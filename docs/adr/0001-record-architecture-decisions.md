# ADR-0001: 설계 결정을 ADR로 기록한다

- 상태: 채택
- 날짜: 2026-10-30

## 배경
1인 프로젝트라도 몇 주가 지나면 "왜 이렇게 만들었는지"를 잊는다. 면접에서도 결과보다 선택의 이유를 묻는다.

## 결정
되돌리기 어렵거나 대안이 여럿인 결정은 `docs/adr/NNNN-제목.md`로 남긴다. 형식은 `template.md`를 따른다.
결정이 바뀌면 기존 문서를 지우지 않고, 새 ADR을 쓰고 기존 문서의 상태를 "대체됨 (ADR-NNNN)"으로 바꾼다.

## 결과
- 좋은 점: 결정의 맥락이 코드와 함께 남는다. PR 리뷰 시 근거를 링크할 수 있다.
- 비용: 결정마다 10분 정도 문서를 쓴다.
